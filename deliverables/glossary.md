| **Cigar Anatomy** | The physical parts of a cigar and their roles: filler, binder, wrapper, cap, head, foot, and shoulder. |  |  |

| **Roller** | The factory worker who makes the cigar, applying the wrapper leaf to the bunch; in some factories one worker both bunches and rolls. | torcedor |  |

| **Curing and Fermentation** | Post-harvest processing of tobacco leaves: curing, fermentation, and ageing. |  |  |

| **Ammonia** | Present in freshly harvested tobacco leaves; proper curing and fermentation rid the leaves of it, and improperly aged cigars deliver a harsh, bitter taste from it. |  |  |

| **Box Aging** | Aging cigars in the original box in which they are packaged, which can exhibit distinctively uniform qualities of taste and aroma. |  |  |
| **Calfrisa** | A climate-controlled curing barn delivering precise humidity and temperature through interior ductwork; uncommon due to expense and construction. |  |  |

| **Carotene** | A plant pigment that replaces chlorophyll in tobacco as the chlorophyll naturally breaks down. |  |  |
| **Casing** | Re-moisturizing aged tobacco so it can be worked with, by dipping in water, misting, or high-humidity storage; also a term for flavoring pipe tobacco. | case |  |
| **Cuje** | The wooden pole in a curing barn from which freshly harvested tobacco leaves hang; cuje cortos run about six feet, cuje largos twelve. | lathe |  |

| **Curing Barn** | The structure where harvested tobacco is stored and dried gradually for roughly 45 days; temperature and humidity determine the curing time. | casa de tabaco |  |
| **Doghouse** | The top vent or opening of a tobacco curing barn where heat escapes and air flows. |  |  |
| **Empilonando** | The process of assembling a pilon or bulk of tobacco for fermentation. |  |  |
| **Ensarte** | The process of transferring harvested tobacco leaves from the fields to the curing barn. |  |  |

| **Hand** | Roughly 30 to 40 tobacco leaves tied together during the curing process; several hands are assembled into a bulk for fermentation. |  |  |
| **Microfermentation** | A specialized ageing process applied to small batches of tobacco to enhance complexity and smoothness. |  |  |
| **Mulling** | An additional fermentation step for tobacco from the periphery of a pilon, exposed to about 100 degrees Fahrenheit and 90% RH in a mulling room for a more complete fermentation. |  |  |
| **Pilon** | A large pile (up to 4,000 pounds or more) of cured tobacco leaves assembled for fermentation; dismantled and reassembled several times over months. | bulk, burro, pilón, trojes |  |
| **Quisqueya** | A rudimentary structure used to cure tobacco in parts of the Dominican Republic; less protective than a traditional curing barn. |  |  |
| **Sarta** | A string used to bind tobacco leaves together during the curing process. |  |  |
| **Tercios** | Tobacco bales wrapped in palm bark, used to age fermented tobacco. |  |  |
| **Yankee Hinge** | The long boards on Connecticut River Valley tobacco barns, designed to swing open to increase airflow. |  |  |

| **Aroma** | The scent of a cigar, lit or unlit, as perceived by the olfactory senses. | bouquet, room note |  |

| **Canoeing** | A burn defect where one portion of the cigar burns hotter and faster than the other; sometimes remedied by touching up the burn with a lighter. |  |  |
| **Cold Draw** | Taking a draw on a cut but unlit cigar to preview its flavors before lighting. | cold taste, dry draw |  |
| **Combustion** | The rate and efficiency at which a cigar burns, influenced by humidity, the tobacco blend, and construction. |  |  |
| **Complexity** | The condition of taste when a cigar produces multiple transitions of flavor. |  |  |

| **V Cutter** | A cutter that carves a V-shape into the head, drawing smoke from the top and bottom of the cigar and concentrating it on the palate. | V-cut, V-cutter, cat's eye, wedge cutter |  |

| **Tobacco Cultivation** | Growing tobacco: seeds, seedlings, primings, shade versus sun growing, and harvesting. |  |  |

| **Cheesecloth** | The material once used to cover shade-grown tobacco fields; today replaced by nylon. |  |  |

| **Seedbed** | The bed where tobacco seedlings sprout; today often trays inside greenhouses, planted in excess as insurance against weather. | cantero |  |

| **Sucker** | An unwanted shoot removed from tobacco plants by workers so nutrients reach the leaves. | suckers |  |

| **Tobacco Seed** | The tiny origin of the tobacco plant; often pelletized in clay for handling, with farmers collecting seeds from prized plants for future crops. | Tobacco Seeds |  |
